### 🧮 数学语法恢复（招牌功能）

某些编辑器认不出 `\( \)` 和 `\[ \]`？点一下 **「∫ 数学转换」**：

```
\(E = mc^2\)   →   $E = mc^2$        （行内，自动区分）
\[∫ e^{-x²}dx\] →   $$∫ e^{-x²}dx$$   （块级，自动区分）
```

- ✅ 自动跳过代码块与行内代码，绝不误伤
- ✅ 转义的 `\$5` 不会被当成公式
- ✅ KaTeX 渲染，公式出错单独标红，不会整页崩

### 🧘 Zen 模式 + 聚焦光带

预览栏点 🧘，世界安静下来：

- **聚焦光带**：视线处的段落全亮，相邻段半亮，其余沉入星空背景
- **光带宽度可调**：1 ~ 9 段随心拉，精读调窄、泛读调宽
- **↑↓ / j / k** 逐段跳读，自动滚到屏幕中央并轻轻"点亮"
- 点击任意段落，光带跟过去；顶底渐隐遮罩，像一条柔和的阅读光带
- `Esc` 随时返回

### ✍️ 批注：读到哪，想到哪

- 选中渲染区任意文字 → 点「✎ 批注」→ 写下想法
- 高亮 + 虚线下划线 + 角标编号，悬停即见内容
- 点高亮可**编辑 / 单条删除**，顶部按钮**一键全清**
- 编辑原文重新渲染后，批注**自动重新挂载**（文本锚定 + 出现次序定位，跨段落选区也行）

### 💬 Obsidian 风格 Callout

```markdown
> [!tip] 一个小提示
> 完整支持 Obsidian 的提示框写法

> [!question]- 还能折叠?
> 类型后加 `-` 默认折叠、`+` 默认展开
```

十余种类型各配图标与主题色：`tip` `note` `info` `warning` `danger` `question` `example` `quote` `bug` `success` `abstract` `important` …… 夜间取 Dracula 色、日间取 Latte 色。

### 🎞 Marp 幻灯片（写 Markdown = 做 PPT）

文档以 front-matter 开头，预览瞬间变成 16:9 幻灯片牌组：

```markdown
---
marp: true
paginate: true
footer: 我的演讲
---

<!-- _class: lead -->
# 封面标题

---

## 第二页
- 公式、代码、Callout 全都能放进幻灯片
```

- ✅ `---` 分页（**代码块里的 `---` 不会误切**）
- ✅ 指令：`paginate` / `class` / `header` / `footer`、页内 `<!-- _class: lead / invert -->`、`<!-- _paginate: false -->`
- ✅ 背景图 `![bg](url)`、`![bg fit](url)`
- ✅ **「▶ 放映」**：全屏深空舞台，流星就在幻灯片背后划过；←→/空格/点击翻页
- ✅ 工具栏 🎞 一键插入模板
